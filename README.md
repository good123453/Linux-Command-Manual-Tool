# Linux Command Manual Tool 🐧

A comprehensive Linux command reference tool that helps beginners learn terminal commands organized by categories.

## Features ✨
- 8 command categories
- Clear explanations for each command
- Safe for learning (does NOT execute commands)
- Interactive menu system
- Perfect for Linux beginners

## Command Categories 📚
1. **Navigation & Directory Commands** - pwd, cd, ls, ls -la
2. **System & User Information** - whoami, uname, history, clear
3. **Network Commands** - ifconfig, ip a, ping, traceroute
4. **File & Directory Management** - mkdir, rmdir, rm, cp, mv
5. **File Viewing & Reading** - cat, less, head, tail
6. **Permissions & Ownership** - chmod, chown
7. **Process & Resource Monitoring** - ps, top, df, du
8. **Admin / Power Commands** - sudo, reboot, shutdown, exit

## How to Use 🚀

1. Run the program:
   ```bash
   python Linux_Command_Manual_Tool.py
   ```

2. Choose a category number (1-8) to see commands
3. Read explanations for each command
4. Type 'y' to exit or 'n' to continue

## Installation 💻
```bash
git clone https://github.com/good123453hey/Linux-Command-Manual-Tool.git
cd Linux-Command-Manual-Tool
python Linux_Command_Manual_Tool.py
```

## Requirements
- Python 3.x installed on your system
- Linux/Unix based system or WSL (Windows Subsystem for Linux)

## Safety Notice ⚠️
- This tool does NOT execute any command
- It is for learning and reference only
- Always understand commands before using them on your system
- Use in a safe environment like a virtual machine for practice

## Features Explained 📖
- **Interactive Menu**: Easy-to-use numbered menu system
- **Categorized Commands**: Commands organized by function
